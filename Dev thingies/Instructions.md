# Unreal Engine Build Checker

This small tool checks the version information embedded in an Unreal Engine game's executable file.

It is intended for files such as:

```text
Pagoda.exe
```

The Dir is hard coded so just change it in ```CheckUnrealBuild.ps1``` If you want to use it.

I Use it to check the Unreal Build of Dead as Disco so that I can update Limelights compatibility sensibly :D
