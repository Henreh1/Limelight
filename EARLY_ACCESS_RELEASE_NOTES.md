# Limelight 0.1.0 Early Access

Limelight brings character mod management and live switching together in one
Dead as Disco themed Windows application.

## Highlights

- Import supported mod ZIP files through the file picker or drag and drop.
- Keep a named character library with duplicate-content protection.
- Switch supported models, materials, textures, portraits, and localisation
  assets while Dead as Disco is running.
- Use the normal Live Loader for manual changes or X19 LLoader for keyboard and
  controller rotation.
- Build reusable profiles and assign a complete cast to X19.
- Run sequential or shuffled X19 rotations with transition safety checks.
- Install, verify, and repair Limelight's managed UE4SS and native bridge files.
- Check local compatibility and create privacy-conscious diagnostic reports.
- Return the game mod folder to a clean state with Purge All Mods.

## Early Access notes

- Nexus Mods browsing and direct downloads remain under construction while
  Limelight's application registration is reviewed.
- Runtime switching depends on each mod's Unreal package structure. Some mods
  that work after a game restart may not be safe to replace live.
- Back up personal mod work before testing it and report reproducible issues
  through the Limelight issue tracker. [HERE](https://github.com/Henreh1/Limelight/issues)

## Included downloads

- `Limelight-0.1.0-early-access-win-x64.zip` contains the standalone portable
  application. Extract the ZIP, then open `Limelight.exe`.
- `Limelight-0.1.0-early-access-win-x64.zip.sha256` can be used to verify the
  download.

Limelight carries and manages its matching Live Loader components itself, so
the native bridge and runtime do not need to be downloaded separately.

Read the documentation at
[henreh1.github.io/LimelightWiki](https://henreh1.github.io/LimelightWiki/).
